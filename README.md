# Hydrate v1.3.1

An Expo React Native hydration tracker with exact editable drink history, volume-aware reminders, premium seasonal themes, analytics, challenges and exports.

## Premium features

- Spring, Summer, Autumn, Winter, Halloween, Christmas, New Year, Valentine, Birthday and Streak Champion themes
- Automatic date-based switching and manual all-year selection
- 30-second locked-theme previews
- Custom theme builder
- Advanced adaptive reminders
- Hydration analytics and challenges
- CSV, PDF and full JSON backup/export
- RevenueCat purchases, restore and subscription management
- Separate `premium`, `seasons` and `holidays` entitlement support

See `RUN_ON_WINDOWS.md` and `PREMIUM_SETUP.md`.
