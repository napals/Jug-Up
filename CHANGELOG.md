# Changelog

## 1.3.1

- Replaced internal build-environment package URLs with the public npm registry.
- Added a project `.npmrc` that explicitly uses `https://registry.npmjs.org/`.
- Removed the obsolete `--experimental-default-type=module` test flag.
- Declared the project as ESM and renamed the Babel config to `babel.config.cjs`.

## 1.3.1

- Added a premium theme engine with automatic seasonal and holiday switching.
- Added Spring, Summer, Autumn, Winter, Halloween, Christmas, New Year, Valentine, Birthday and Streak Champion themes.
- Added manual theme selection and premium previews.
- Added RevenueCat entitlement, purchase, restore and manage-subscription integration.
- Added a web/Expo Go developer demo entitlement for pre-store UI testing.
- Added premium 30, 90 and 365-day analytics.
- Gated advanced adaptive reminders behind Hydrate Plus while retaining fixed reminders for free users.
- Added EAS development, preview and production build profiles.
- Added theme resolution regression tests and store setup documentation.

- Added remaining-volume-aware reminders and exact editable drink history.
